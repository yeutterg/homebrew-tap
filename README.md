# homebrew-tap

Personal Homebrew tap.

## Install

```bash
brew tap yeutterg/tap
brew install termag-agent
brew install --cask bookshelfbar
```

| Name | What |
|---|---|
| `termag-agent` | Formula |
| `bookshelfbar` | Cask: [BookshelfBar](https://github.com/yeutterg/bookshelf-bar), a macOS menu bar app for KEF speakers |
